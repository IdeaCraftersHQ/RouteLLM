# RouteLLM Marketing Content Strategy

## 1. Core Themes
- **Cost vs Quality**: Proving 85% savings while keeping 95% performance.
- **Developer Experience**: "Drop-in" compatibility with OpenAI.
- **Open Standards**: Built on LMSYS/Anyscale research.

## 2. Content Mix
- **Technical Whitepapers**: Benchmarking routers on GSM8K and MMLU.
- **Case Studies**: Real-world scenarios (e.g., routing math to specialized models).
- **Social "Quick Tips"**: How to calibrate thresholds in 1 minute.
- **Architecture Deep Dives**: Moving from Python to Go for the routing layer.

## 3. Channels
- **X (Twitter)**: Target LLM developers and researchers.
- **LinkedIn**: Focus on AI platform engineers and CTOs.
- **GitHub**: High-quality README and example notebooks.
- **LMSYS Blog**: Academic and research-focused deep dives.
